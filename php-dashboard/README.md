# PHP Dashboard – ParentControl

## One-Click Install
1. Upload this entire `php-dashboard/` folder to your PHP host (Apache/Nginx with PHP 7.4+).
2. Open `install.php` in browser.
3. Fill in DB credentials, admin username/password, and Node.js Render URL.
4. Click **Install Now** – database tables are auto-created.
5. **Delete `install.php`** after setup.

## Login
- Go to `login.php` (auto-redirected if not logged in).
- Use the admin credentials set during install.

## Features
- View all connected Android devices
- One-click Live View (WebRTC stream)
- Capture Photo / Audio / Video from any device
- Auto-delete captured media after 24 hours
- Download or manually delete captures
